## 产品基本信息
- **工具名称**：Claude
- **一句话定位**：Anthropic 开发的 AI 助手，以长文本理解、严谨推理和企业级安全著称
- **核心技术/模型**：Claude Opus / Sonnet / Haiku 系列大模型
- **官网地址**：[claude.ai](https://claude.ai)

## 核心功能与场景
- 智能对话：多轮深度对话，长上下文窗口支持整本文档级分析
- 代码生成：Claude Code 智能体可自主完成多步骤编程任务，企业 API 支出份额领先
- 文档处理：上传 PDF、Word 等文件进行摘要、翻译与结构化分析
- Artifacts 创作：实时预览生成的网页、图表与文档作品
- API 服务：通过 Anthropic API 为企业提供模型能力

## 使用场景
- 长文写作与审校：合同、报告、论文的阅读理解与改写
- 工程开发：Agentic Coding，配合 IDE 或 CLI 完成复杂重构
- 企业知识库：结合内部文档做问答与决策支持
- 数据分析：表格与图表的解读与可视化生成

## 技术优势与特点
- 长文本能力突出，适合处理大型代码库与长文档
- 输出风格严谨、幻觉率低，适合对准确性要求高的场景
- 企业市场认可度高，安全与合规能力完善
